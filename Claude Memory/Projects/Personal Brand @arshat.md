## Аудит 2026-06-14 (Instagram Profile Pack)

**Общая оценка:** 30–35% реализации потенциала.

**Что работает:**
- Верификация — сильнейший trust signal
- Первая строка bio: «Best CMO in Kazakhstan 2025» с тегом источника
- Username @arshat — чистый, брендируемый
- 397 постов — дисциплина активности
- Недавний контент (KMC 2026, Kazakhstan Marketing Conference) — правильный экспертный контекст

**Критические проблемы:**
1. Bio без роли и ценностного предложения (перечисляет прошлое, не говорит что делает сейчас)
2. ==30+ хайлайтов — все туристические== — убивает профессиональное позиционирование
3. Нет ссылки в bio (только Threads) — упущенная конверсия
4. Нет CTA в bio
5. Опечатка: «Enterpreneurship» → «Entrepreneurship»
6. Некорректный эмодзи: 🔭 для Bolashak
