# Консьерж-служба холдинга Almaly

**Статус:** 🟡 В работе  
**Дедлайн:** 28.10.2026 (по письму Аршата Данияру 19.10.2026; ранее 30.10)  
**Объекты:** МПО · Rahat Palace · Qazaq Auyl

## Контекст

Задача — разработка и внедрение консьерж-службы для отельного кластера холдинга KUA Almaly (три объекта):
- **Медео Парк Отель (МПО)** — городской формат
- **Rahat Palace** — люкс-сегмент
- **Qazaq Auyl** — загородный

Ключевые параметры:
- Стоимость реализации: 61–115 млн ₸/год (зависит от выбранной модели)
- Новый закон о персональных данных (вступил в силу 02.10.2026) — напрямую применяется к консьерж-функции (сбор, обработка данных гостей)
- Туристический контекст: 754 тыс. иностранных туристов в Казахстане (2025)
- Конкурентная среда: Four Seasons Chat, Ten Lifestyle (Великобритания), MGM, Quintessentially

## Рекомендация

Единый централизованный консьерж-хаб для всех трёх отелей холдинга (vs. отдельные команды на каждый объект). Преимущества: разделение ФОТ, единый стандарт сервиса, масштабируемость на новые объекты.
