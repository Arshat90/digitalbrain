# Drone Delivery Almaty

Инициатива по запуску дрон-доставки в Алматы: сеть из 4 боксов (Самал / Аксай / Шанырак / Жетысу), 15 дронов M400, орбита до 20 км. Базовый расчёт 25–30 рейсов/день на дрон, выручка 162 млн ₸/год на пике.

> [!warning] Главный вывод деки
> При тарифе 1 200 ₸ модель **не окупается за 5 лет**. Нужен один из трёх рычагов:
> - **Multi-stop** (рекомендуем — окупаемость ~4 года)
> - **Премиум-тариф 2 200 ₸**
> - **Городская субсидия**
>
> Рекомендация — стартовать с малого пилота (3 дрона / 1 бокс) на 6 мес, проверить unit-экономику, и только потом масштабировать на 15 дронов.

4. **Три рычага окупаемости** — multi-stop / премиум / субсидия

- **Акимат / КГА:** BVLOS-разрешение для M400 >25 кг — критический регуляторный gate
