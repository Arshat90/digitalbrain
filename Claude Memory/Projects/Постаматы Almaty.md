# Постаматы / Luggage Storage Almaty

Инициатива по запуску сети постаматов / luggage-storage в Алматы на базе китайских OEM-решений. Универсальный RFI готов под три типа партнёров одновременно.

## Целевая аудитория RFI

- **OEM-производители** оборудования (постаматы, шкафы хранения)
- **Операторы действующих сетей** в Китае
- **Потенциальные JV-партнёры** под локализацию в РК

## Деливерабл

`RFI_Постаматы_Партнёры_RU_ZH.docx` — 2 страницы, A4, две колонки (русский / 中文), **34 вопроса в 8 тематических блоках**:

1. **Общая информация** — формат сотрудничества, опыт, референсы
2. **CAPEX** — стоимость шкафов, монтаж, MOQ, интеграция с Kaspi/банками
3. **OPEX** — SaaS, M2M-трафик, энергия, field-команда, ТО
4. **Прочие расходы** — запчасти, MTBF, гарантия/SLA, страхование, лицензии
5. **Операционные показатели** — утилизация по сценариям, чек, конверсия, окупаемость
6. **Ограничения и безопасность** — IP, CCTV, KYC, запрещённые предметы, emergency
7. **Накопленный опыт** — инциденты, кражи, регуляторика, неудачные пилоты
8. **Договорные условия** — revenue-share, локализация, JV, контактное лицо

Внизу — благодарственный блок и контактное поле.
