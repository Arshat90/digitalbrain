# Annual Report Framework

## Суть

Промпт-инжиниринговый фреймворк для генерации **годового маркетинг-отчёта**. Построен и отработан для собственного применения. **Фреймворк активен и переиспользуется** — конкретные цифры ниже относятся к циклу 2025 года.

## Две версии фреймворка

1. **Версия с CSV-экспортом из Outlook** — сборка из писем и календаря
2. **Версия с путями к папкам** — обход файловой структуры рабочих документов

## Применение (цикл 2025)

Использован при подготовке к **ежегодной встрече 1:1 с президентом холдинга** (начало 2026). Годовые еженедельные отчёты трансформированы в **value-framed executive summary**.

- **Alex Sary Agash** — бренд воды вышел на **#1 позицию в Казахстане**
- **569 млн тенге** — экономия бюджета

- Запуск **внутреннего креативного агентства**

## Шаблон промпта

> Два режима — выбери один в зависимости от доступного источника данных.

### Режим A — из Outlook (CSV-экспорт)

Скопируй блок ниже в новый чат:

---

Помоги подготовить **годовой маркетинг-отчёт** для 1:1 с президентом холдинга.

**Период:** `{{YYYY}}`
**Источник:** прикреплённый CSV-экспорт из Outlook (письма + календарь за год)
**Аудитория:** президент холдинга — executive, value-framing, без операционной детали

Из CSV извлеки и структурируй:
1. **Headline-результат** — одна цифра или событие, которое определило год
2. **Финансовый эффект** — экономия бюджета, выигрыш в переговорах, ROI-ориентиры
3. **Ключевые проекты** — топ-5, каждый в формате: название → результат → значение для холдинга
4. **Стратегические треки** — что запущено на будущий год (если есть сигналы)
5. **Аномалии / риски** — что не пошло по плану, как исправлено

Формат вывода: связный executive summary, не буллеты. Тон — уверенный, цифры везде где есть. Финальный документ — Word (.docx).

### Режим B — из файловой структуры

---

Помоги подготовить **годовой маркетинг-отчёт** для 1:1 с президентом холдинга.

**Период:** `{{YYYY}}`
**Путь к папке с документами:** `{{C:\Users\...\Маркетинг\2025\}}`
**Аудитория:** президент холдинга — executive summary, value-framing

Обойди структуру папки, найди отчёты, презентации, переписку. Структура вывода — та же, что в Режиме A (Headline → Финэффект → Проекты → Треки → Аномалии). Сохрани итог в Word (.docx).
