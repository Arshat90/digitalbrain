# Claude Training — Marketing Team

## Суть

Внутренняя программа обучения маркетинговой команды холдинга работе с Claude и связанной AI-инфраструктурой. Цель — масштабировать продуктивность команды через AI-партнёрство, не делая обязаловку, а закрепляя там, где экономит время сотруднику.

## Контекст

- **Аудитория:** маркетинг-команда холдинга (Almaly Assets Management)
- **Подход:** 4-уровневая лестница навыков
    - L1 (всем): формула 9 элементов, итерационная работа, безопасность
    - L2 (продвинутые): Project + 3 Skills + критика
    - L3 (аналитики/менеджеры): Claude Code + Subagents + MCP
    - L4 (амбассадоры): свои Skills + Hooks + аудит
- **Привязка к реальным задачам холдинга:** hospitality, F&B, ВНД, Kaizen, Telegram-боты, ассортимент, presentations для инвесторов

## Концепция

> [!quote]
> «Не учим работать с AI — учим быть продуктивнее с новым членом команды Claude.»

Прикладной формат, модульность, привязка к ролям, безопасность по умолчанию.

- +3× скорость драфта
- ≥20 промптов в общей библиотеке
