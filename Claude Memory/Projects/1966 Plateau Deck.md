# 1966 Plateau Deck

## Спецификация стиля

- **Язык:** английский
- **Длина:** 16 слайдов
- **Тон:** investor/strategic brief — без маркетинговой воды
- **Формат:** long-form prose на каждом слайде (не буллеты)
- **Дизайн:**
    - Small-caps section labels
    - Footer: `ALMALY HOLDING · CONFIDENTIAL · 2025`
    - Slide counter: `X / 16`
