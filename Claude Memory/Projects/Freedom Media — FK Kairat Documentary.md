# Freedom Media — ФК Кайрат Documentary

> [!abstract] TL;DR
> Сделка по продаже прав на документальный фильм о ФК «Кайрат» медиаплатформе Freedom Media. ==50 млн ₸==, 4 серии, эксклюзив 3 года. Письмо Акционеру подготовлено, ожидаем согласования.

## Суть

Переговоры о продаже прав на документальный фильм о ФК «Кайрат» для размещения на стриминге Freedom Media. Переговоры ранее вёл режиссёр Айсултан Сеитов — коммуникация передана Аршату.

## Условия (текущее предложение Freedom Media)

- **Стоимость прав:** ==50 000 000 ₸== *(требует подтверждения: ₸ или USD)*
- **Объём:** документальный фильм, ==4 серии==
- **Эксклюзивные права:** ==3 года==
- **Медиаподдержка** (отдельный контракт): совместные посты с ФК «Кайрат» в Instagram клуба; ролики Дастана Сатпаева (#10, нападающий) и Темирлана Анарбекова (вратарь) — формат «лайк + переход»; размещение 1-й серии на YouTube Freedom Media Originals + совместный пост ФК «Кайрат»
- **Премьера:** на базе ФК «Кайрат»; организует Freedom, база — только площадка. Без сторонних логотипов/стендов; брендированные авто (например, «Аллюр») допустимы
- **Выход:** ==июль 2026==; серии между матчами; права продаются эксклюзивно Freedom
