# Медео Парк Отель — Пре-опенинг и коммуникации

## Контекст

Клиент — Медео Парк Отель. Задача: пре-опенинг и коммуникационная стратегия. Скоуп: отель + плаза + апартаменты.

Концепция: от ретро-стилистики — к «соединение природы и современного городского человека». Бренд-кампания делалась с Лондоном ~1,5 года назад, стратегия устарела из-за переносов запуска.

## Статус (по встрече 09.06.2026)

- Soft opening 15 июня: продажи только через свой сайт + walk-in + MICE-агенты («гости, которых не жалко»), 20–30 номеров, без OTA/Booking. До 15 июля — наращивание.
- СПА — подрядчик даёт готовность 1 сентября. Стройка задерживает (лобби).
- Цены: софт ~120К ₸, целевой тариф 200К ₸/ночь (компенсация: бесплатный минибар, кофемашина, сильный завтрак). Бани — 50К ₸/2 часа.
- Решение по ивентам: ДВА мероприятия. (1) Гранд-опенинг для СМИ/блогеров/турагентов/корп.клиентов — ориентир пт–сб 4–5 сентября. (2) ДР акционера ~конец августа (отель заблокирован ~неделю) — закрытое, команда пока не вовлечена. От гала-ужина в балруме отказались (дублирует ДР).
- Концепт гранд-опенинга: оркестр на плазе (современные аранжировки казахской/советской классики), тур по отелю с авторскими коктейлями («покоритель горных вершин»), афтепати с диджеем (ремиксы Дос Мукасан и пр.), ночёвка-квоты 10–15 для блогеров/СМИ по бартеру, ужин на террасе, утром тропинка/йога/завтрак. Вместо ленточки — снятие шёлка с арт-объекта (Хан-Тенгри / Медельбеков). Яндекс Ultima — трансфер + цветочное оформление салонов (бартер).
- Агентство по гранд-опенингу — на паузе; концепт делает внутренняя команда, агентство потом только на реализацию (через тендер).
- Проблемы: блогеры лезут на стройку-тропинку («Жумбак Жол 2», вирусные ролики) — обсуждается форсированное открытие маршрута после оценки безопасности; Wi-Fi/TV в номерах — шеринг/стриминг не работают.
- SMM: рилсы + фотокампания готовы; основной ролик не доснят, вертикальной версии не будет. Платная реклама: Meta + наружка, аэропорт дорого (~19 млн ₸/мес тимбанер). Запуск соцсетей ускорить к 15 июля.
- С 16 июня выходит новый диджитал-маркетолог (вместо Иры).
