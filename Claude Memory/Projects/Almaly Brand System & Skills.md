# Almaly Brand System & Skills

> [!abstract] TL;DR
> Стратегия поднятия visual-deliverables с ~7/10 до ~9/10: бренд-система дизайн-токенов + сюит скиллов. 4-фазный роадмап. Netlify MCP для лендингов ДЗО с CMS-вариантами для almaly.kz.

## Суть

Проект по созданию дизайн-системы и инструментов стандартизации HTML/web-deliverables Алмалы. Инициирован аудитом текущего стека + исследованием Netlify и CMS-вариантов.

## Аудит стека (2026-06-16)

**Сильные стороны (подтверждены ресёрчем):**
- Single-file HTML + base64 + Chart.js — best practice для offline-доставки
- RU/KZ покрытие, мобильность, калькуляторы — правильный выбор

**Слабости:**
- Каждый дек с нуля → дизайн «плывёт», сваливается в AI-клише
- Сайты — ad-hoc уровень (~5/10)

**Оценки:** деки ~7/10 → с бренд-системой + скиллом ~9/10; сайты ~5/10 → ~8/10

## Технический стек

**Деки (offline):** reveal.js + Chart.js (основа); Pandoc для схлопывания в один файл; Slidev для PDF
**Сайты:** быстрый = HTML + Tailwind CDN + Alpine + GSAP (GSAP с апреля 2025 ==полностью бесплатен==, вкл. все плагины); серьёзный = Astro + Tailwind + shadcn/HyperUI
**Деплой:** Netlify (официальный MCP-коннектор в Cowork — управление из чата)
**Графики:** Chart.js (default) + ECharts (карты КЗ, гейджи)
**Казахский:** Google-шрифты с «Cyrillic» — покрывают все казахские глифы, отдельный шрифт не нужен

## Netlify MCP для ДЗО

Возможности: preview-URL на каждую версию; формы (lead capture без бэкенда, Akismet антиспам, уведомления в Slack/Telegram); A/B-тесты трафика; редиректы (QR на печатных носителях); аналитика без cookies; пароль на страницу (Pro)

Кейсы: лендинги Медео Парк Отель (форма брони), I'M ресторанов (банкет), Аптеки (запись), Постаматы (предзаказ)

## CMS для almaly.kz newsroom

Netlify = хостинг. CMS — отдельно (webhook → build hook → авторебилд):

| CMS | Тип | Рекомендация |
|-----|-----|---|
| ==Storyblok== | SaaS, WYSIWYG | Лучший для нетехн. команды (~$90/мес) |
| ==Sanity== | SaaS, flexible | Мощнее + щедрый free tier; реалтайм-совместная работа |
| Decap CMS | Git-based, бесплатно | MVP быстрого старта (слабее по медиа/ролям) |
| Strapi / Directus | Self-hosted | Если данные внутри периметра холдинга |
