# ВНД Agent

## Суть

Внутренний AI-агент для подготовки **внутренних нормативных документов** (ВНД) холдинга — POL, REGWRK, PRO, WIN, REGDEP, JD, REGCOM. Адаптирован под стандарт APS-PRO-001 и 13 принципов валидации; рассчитан на использование лидером блока для разработки документов, обязательных к исполнению в 50+ ДЗО.

Локальная папка: `C:\Users\LENOVO\Documents\Claude\Projects\ВНД`. Skill-файлы: `vnd-agent.md` (новый агент-консультант), `vnd-prepare.md` (старый интервьюер), `legal-expert-rules.md`, `validation-13.md`, `variable-map-schema.json`.

## Архитектура агента (целевая, 2026-05-06)

Переход от **интервьюера** (`vnd-prepare`) к **эксперту-соавтору** (`vnd-agent`) — три одновременные роли:

- **Методолог ВНД** — стандарты APS-PRO-001, типы документов, требования юриста
- **Отраслевой эксперт** — предметная экспертиза по блоку (MAR/FIN/HR/LEG/BUS/ITS/PRS): KPI, бюджетирование, оценка, договорная работа и т.д.
- **Критический партнёр** — оценивает ответы пользователя через юр. правила + ДЗО-тест на исполнимость

### Поток работы (6 фаз)

1. **Стартовый экран** — приветствие + 4 структурированных вопроса (блок, тема, уровень применения, наличие черновика)
2. **Диагноз** — определение блока, темы, типа документа, области применения
3. **Интернет-исследование** — 6 поисковых запросов (3 RU + 3 EN), ≥5 источников, синтез best practices и типичных упущений
4. **Профилирование** — черновик структуры с предлагаемым контентом (пользователь редактирует, не отвечает на анкету)
5. **Экспертное наполнение** — по разделам, с конкретными формулировками из предметной базы
6. **Критическая проверка + генерация .docx + автовалидация** по 13 принципам
