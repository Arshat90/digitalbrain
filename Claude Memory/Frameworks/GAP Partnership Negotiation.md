# GAP Partnership Negotiation

## Суть

**Методология переговоров** от The Gap Partnership. Упор на структурированный подход: подготовку, контроль переменных, работу с мандатами и измерение выигрыша.

## Доказанная применимость

В годовом цикле методология принесла **$133 609 выигрыша в переговорах** — зафиксировано в executive summary для президента холдинга.

## Роль в функции

Один из опорных инструментов маркетинг-функции как **profit center**:
- Партнёрские переговоры
- Закупочные переговоры через маркетинг
- Переговоры в M&A-треках
