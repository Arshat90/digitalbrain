# Hoshin Kanri X-matrix

## Суть

Японский метод **стратегического планирования**, визуализирующий связь между долгосрочной стратегией, годовыми целями, тактикой, метриками и ответственностью в формате **X-матрицы**.

## Четыре квадранта

1. **Breakthrough Objectives** (3–5 лет) — прорывные долгосрочные цели
2. **Annual Objectives** — годовые цели, выводящие к прорыву
3. **Top-level Improvement Priorities** — приоритетные инициативы
4. **Metrics / Targets to Improve** — показатели успеха

Между квадрантами — **матрица корреляций**: какая инициатива закрывает какую цель и какой метрикой измеряется.

## Применение

Используется в стратегическом планировании холдинга — связка между годовым циклом и 3–5-летним горизонтом.
