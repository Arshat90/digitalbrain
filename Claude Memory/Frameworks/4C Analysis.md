# 4C Analysis

## Суть

Фреймворк бизнес-анализа: **Company, Customers, Competitors, Context** (или вариация: Company, Customer, Competition, Channels). Используется для структурированной проработки новых бизнес-моделей и M&A-кандидатов.

## Доказанные применения в работе

### 1. Tech/Equipment Rental
- Модель проката техники и оборудования для алматинского рынка
- **Бенчмарк:** «Все в аренду»
- Формат: **Word-документ** с SWOT-матрицей и инвестиционной дорожной картой

### 2. Gastronomy / Brewery Restaurant
- Концепт гастро-брюерни для Алматы
- **Бенчмарк:** «Птицы захмелели» (Сочи)
- Формат: **Word-документ** с SWOT-матрицей и инвестиционной дорожной картой

## Стандартный формат deliverable

- Word (.docx)
- Структура: 4C → SWOT → Investment Roadmap
- Русский язык

Формат deliverable — Word-документ (.docx) на русском языке. Структура строго:

1. **Company** — внутренний потенциал, ресурсы, компетенции, UVP
2. **Customers** — сегменты, объём, поведение, Jobs-to-be-done
3. **Competitors** — прямые и косвенные, позиционирование, доли рынка
4. **Context** — макро (PESTEL-выдержка), тренды, регуляторика, сезонность
5. **SWOT** — 4 квадранта, не менее 4 пунктов каждый, вытекают из 4C
6. **Investment Roadmap** — 3 этапа (Запуск / Рост / Масштаб): сроки, CAPEX-ориентир, KPI-checkpoint на выходе каждого этапа

Стиль: деловой русский, конкретные цифры и бенчмарки где возможно, никаких общих слов без обоснования. Сохрани файл в рабочую папку и дай ссылку.
