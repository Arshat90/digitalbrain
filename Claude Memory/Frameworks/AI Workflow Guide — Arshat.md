# AI Workflow Guide — Arshat Baktygali

> [!abstract] Что это
> Персональная инструкция по работе с тремя AI-инструментами: **Claude (Cowork)**, **ChatGPT**, **Perplexity**. Включает готовые промпт-шаблоны под твои реальные задачи, правила роутинга и cross-tool workflows. Документ живой — обновляй по мере появления новых паттернов.

---

## Часть I. Архитектура: какой инструмент для чего

### Главное правило

> [!tip] Принцип разделения труда
> **Perplexity** — добывает факты с источниками (разведчик).
> **ChatGPT** — шлифует промпты и выдаёт черновики быстро (мастерская).
> **Claude** — синтезирует, создаёт финальные документы, управляет vault (штаб).

### Матрица роутинга

| Задача | Инструмент | Почему |
|--------|-----------|--------|
| Создать DOCX, PPTX, XLSX | Claude | Навыки + файловый доступ |
| Работа с Obsidian vault | Claude | MCP-интеграция |
| Длинный аналитический текст | Claude | 200K контекст, держит нить |
| Перевод RU↔EN↔KK | Claude | Точность в рабочем контексте |
| Быстрый черновик / brainstorm | ChatGPT | Canvas, скорость итерации |
| Улучшить/написать промпт | ChatGPT | Canvas, итеративная шлифовка |
| Аудит своих промптов | ChatGPT | Анализ паттернов |
| Исследование рынка | Perplexity | Real-time + источники |
| Проверка фактов / цифр | Perplexity | Автоматическая цитация |
| Конкурентный мониторинг | Perplexity | Актуальная база |
| Новости отрасли | Perplexity | Свежие данные с URL |
| n8n: классификация / теги | Claude Haiku (API) | В 20x дешевле Sonnet |
| n8n: генерация ответов | Claude Sonnet (API) | Баланс качество/цена |

### Когда не использовать Claude для поиска

Если задача начинается со слов «найди», «что сейчас», «какая цифра», «сравни последние данные» — сначала иди в Perplexity. Принеси данные в Claude уже верифицированными.

## Часть II. Claude (Cowork) — шаблоны

### Формула каждого запроса

```
[КОНТЕКСТ — 1 строка] + [ЗАДАЧА — глагол + объект] + [ФОРМАТ] + [ОГРАНИЧЕНИЯ]
```

Всегда указывай: язык, объём, аудиторию, что НЕ нужно делать.

### Vault-операции

#### Обновить статус проекта
```
Прочитай Claude Memory/Projects/[НАЗВАНИЕ].md (только секции Status и Changelog).
Обнови:
- Status: [новый статус]
- Добавь в Changelog: «[дата]: [что произошло]»
Без переписывания остального контента.
```

#### Достать информацию по проекту
```
Прочитай Claude Memory/Projects/[НАЗВАНИЕ].md.
Ответь на вопрос: [вопрос]
Кратко, только факты из файла. Если нет — скажи прямо.
```

#### Массовое обновление нескольких проектов
```
Обнови три проекта одним проходом:

1. Claude Memory/Projects/AGS Brand Development.md
   Changelog: «2026-05-02: [событие]»

2. Claude Memory/Projects/EDA.md
   Status → «[новый статус]»

3. Claude Memory/Projects/AMC.md
   Changelog: «2026-05-02: [событие]»

Для каждого — только patch, не перезаписывать файл целиком.
```

### Документы и deliverables

#### Briefing для стейкхолдера (1 страница)
```
Прочитай Claude Memory/Projects/[ПРОЕКТ].md.
Напиши 1-страничный briefing для [ИМЯ/РОЛЬ].
Язык: [русский/английский]
Структура: ситуация → ключевое решение → следующий шаг → риски
Объём: 250–300 слов. Деловой стиль. Без bullet points. Без intro-абзаца.
```

#### Email партнёру / стейкхолдеру
```
Контекст: [1 строка о ситуации]
Напиши email от моего имени для [ИМЯ], [роль].
Цель письма: [что нужно достичь]
Тон: [деловой / партнёрский / срочный]
Язык: [русский/английский]
Объём: до 150 слов. Без приветственных формальностей кроме первой строки.
```

Пример для Emelie (Ecole Ducasse):
```
Контекст: AGS co-branding — ждём финального подтверждения по правилам использования логотипа ED в пространстве Gastrocentre.
Напиши email от моего имени для Emelie Leducq, Paris HQ Ecole Ducasse.
Цель: мягко напомнить о pending approval, предложить звонок на этой неделе.
Тон: партнёрский, тёплый, без давления.
Язык: английский. Объём: до 120 слов.
```

#### Investor brief / pitch-раздел
```
Данные: [вставить данные или указать файл]
Напиши раздел «[название раздела]» для investor brief [ПРОЕКТ].
Аудитория: [институциональные инвесторы / семейные офисы / уточнить]
Язык: английский. Тон: уверенный, фактурный, без хайпа.
Объём: [150–200 слов / 1 слайд / 3 абзаца]
Без общих фраз — только цифры и конкретика.
```

#### Пост для Instagram
```
Напиши Instagram-пост для [бренд/проект].
Тема: [тема]
Аудитория: [Алматы, 25–45, интересы]
Тон: [живой / официальный / вдохновляющий]
Язык: [русский / казахский]
Структура: хук (1 строка) → тело (3–4 строки) → CTA → 5–7 хэштегов
Без корпоративного языка. Без emoji в тексте.
```

#### Перевод документа
```
Переведи следующий текст с [язык] на [язык].
Контекст: [деловой документ / маркетинг / юридический]
Сохрани структуру оригинала. Адаптируй под деловой стиль [казахстанского рынка / европейского партнёра].
Не объясняй — сразу давай перевод.

[ТЕКСТ]
```

#### PPTX-презентация
```
Создай презентацию [НАЗВАНИЕ] в формате .pptx.
Аудитория: [кто]. Язык: [язык]. Слайдов: [N].
Структура:
1. [название слайда] — [содержание]
2. [название слайда] — [содержание]
Стиль: [корпоративный / минималистичный / инвесторский]
Данные: [вставить или указать файл]
```

### Анализ и фреймворки

#### GAP-анализ
```
Проведи GAP-анализ для [проект/направление].
Текущее состояние: [описать]
Целевое состояние: [описать]. Горизонт: [срок]

Данные: [вставить или указать файл]
Структура: Customer → Cost → Convenience → Communication
Для каждого: 3–5 конкретных тезисов. Без общих слов.
Язык: русский.
```

```

Годовые цели: [перечислить]
Приоритеты: [перечислить]. KPI: [перечислить]. Ответственные: [перечислить]
Выдай как таблицу Markdown. Язык: русский.
```

## Часть III. ChatGPT — шаблоны

### Главный принцип: используй Canvas

Все задачи по написанию и улучшению промптов делай в Canvas-режиме. Canvas позволяет итеративно редактировать без накопления лишней истории.

---

#### Промпт-кузница (написать промпт для Claude)
```
Я работаю в Claude (Cowork mode, Anthropic).
Мне нужен промпт для задачи:

ЗАДАЧА: [опиши что хочешь получить]
КОНТЕКСТ: Arshat Baktygali, Marketing Director, холдинг Almaly, Алматы, Казахстан
НУЖНЫЙ РЕЗУЛЬТАТ: [описание идеального output]

Требования к промпту:
- Краткий (до 8 строк)
- Контекст + задача + формат + ограничения
- XML-теги если задача сложная
- Явно указывает язык и объём
- Негативные инструкции (что НЕ делать)

Напиши финальный промпт для вставки в Claude.
```

#### Аудит своих промптов (раз в месяц)
```
Вот мои последние промпты из Claude:

[вставить 5–10 промптов]

Найди паттерны неэффективности. Ответь:
1. Что делаю правильно (сохранить)?
2. Три главных ошибки снижающих качество ответов?
3. Улучшенная версия самого слабого промпта?

Будь конкретным. Без общих советов.
```

#### Улучшить конкретный промпт
```
Вот мой промпт для Claude:

[вставить промпт]

Улучши: сделай короче и точнее, убери лишнее, добавь контроль длины.
Покажи: [оригинал] → [улучшенная версия] → [что изменил и почему].
```

#### Быстрый черновик документа
```
Напиши черновик [тип документа] на тему [тема].
Это черновик для доработки в другом инструменте — не шлифуй.
Структура: [разделы]. Язык: [язык]. Тон: [тон]. Объём: [объём].
```

#### Обратная связь по тексту
```
Вот мой текст:
[вставить]

Дай критику по трём критериям:
1. Структура (логика, порядок)
2. Тон (соответствует ли аудитории)
3. Конкретность (размытые формулировки)

Для каждой проблемы — конкретное предложение как исправить.
```

## Часть IV. Perplexity — шаблоны

### Главный принцип: Deep Research + Fail-Fast Clause

Для серьёзных исследований — всегда Deep Research mode. Всегда добавляй в конец:
```
Cite every key claim with a URL. If you can't find a verified source, mark it [UNVERIFIED].
```

---

#### Анализ рынка / сегмента
```
Сделай анализ рынка [сегмент] в Казахстане / Центральной Азии.
Горизонт данных: 2024–2026.
Включи: объём рынка, ключевые игроки, тренды, регуляторный контекст.
Источники: только официальные отчёты, новостные издания, отраслевые ассоциации.
Cite every claim with a URL. Mark unverified data as [UNVERIFIED].
```

Пример для AMC:
```
Анализ рынка горнолыжного туризма Казахстана и Центральной Азии, 2023–2026.
Включи: посещаемость курортов, инвестиции в инфраструктуру, сравнение с Кыргызстаном / Узбекистаном / Грузией, государственные программы поддержки.
Deep Research. Cite every claim with a URL.
```

#### Конкурентный анализ
```
Найди информацию о компании/бренде [НАЗВАНИЕ].
Что нужно: последние новости, изменения в позиционировании, маркетинговые активности, партнёрства.
Период: последние 6–12 месяцев. Cite sources with URLs.
```

#### Проверка факта
```
Проверь утверждение: «[утверждение]»
Найди: подтверждающие источники ИЛИ опровержение.
Ответ: [ПОДТВЕРЖДЕНО / ОПРОВЕРГНУТО / НЕВЕРИФИЦИРОВАНО] + источники с URL.
```

#### Подготовка к переговорам
```
Я готовлюсь к встрече с [имя/компания].
Найди:
1. Последние публичные активности (новости, пресс-релизы)
2. Ключевые люди (CEO, партнёры, ЛПР)
3. Потенциальные интересы и болевые точки
4. Что они могут хотеть от этой встречи

Период: последние 12 месяцев. Cite sources with URLs.
```

Пример для Ecosign:
```
Я готовлюсь к встрече с Eric Callender, Ecosign Canada.
Найди: последние проекты Ecosign, подход к горным курортам в развивающихся рынках, кейсы в СНГ/Центральной Азии.
Cite sources with URLs.
```

## Часть V. Cross-tool Workflows

### Workflow 1: Research → Document (Perplexity → Claude)
```
1. Perplexity Deep Research: [исследовательский запрос + fail-fast clause]
2. Скопировать результаты (текст + источники)
3. Claude: «На основе следующих данных [вставить] напиши [тип документа].
   Используй только факты из предоставленных данных.
   Язык: [язык]. Формат: [формат]. Объём: [объём].»
```
Применение: investor briefs с рыночными данными, аналитика для Акимата по AMC, competitive positioning для ZILLI.

---

### Workflow 2: Prompt Refinement → Execution (ChatGPT → Claude)
```
1. ChatGPT Canvas: «Напиши промпт для Claude для задачи: [задача]» — итерировать
2. Скопировать готовый промпт
3. Claude: вставить → получить результат с первого раза
```
Применение: новые типы задач которые ещё не шаблонизированы.

---

### Workflow 3: Draft → Finalize (ChatGPT → Claude)
```
1. ChatGPT: «Напиши быстрый черновик [документа]. Не шлифуй.»
2. Claude: «Вот черновик [вставить]. Доработай до финального качества:
   Стиль: [стиль]. Язык: [язык]. Сохрани структуру. Объём не менять более чем на 20%.»
```
Применение: посты, письма, разделы презентаций когда нужна скорость.

---

### Workflow 4: Monitoring → Vault (Perplexity → Claude)
```
1. Perplexity Space: еженедельный дайджест по настроенным темам
2. Claude: «Вот дайджест новостей [вставить].
   Обнови проекты в vault если есть релевантное:
   - AMC: горный туризм Казахстана
   - ZILLI: luxury retail
   - EDA: Ecole Ducasse
   Формат: append в Changelog с датой и источником.»
```

---

### Workflow 5: Meeting Prep (Perplexity → Claude → Vault)
```
1. Perplexity: «Я готовлюсь к встрече с [имя]. [шаблон подготовки к переговорам]»
2. Claude: «На основе этих данных [вставить] создай 1-страничный meeting brief.
   Структура: контекст → их интересы → мои цели → ключевые вопросы → риски.
   Язык: русский. Без bullet points. 300 слов.»
3. Claude: «Сохрани как Claude Memory/Projects/[ПРОЕКТ]/Meeting Briefs/[дата]-[имя].md»
```

## Часть VII. Ежедневная рутина (5–10 мин утром)

1. Perplexity Spaces → просмотреть дайджест мониторов
2. Claude (если есть релевантные новости) → батч-обновление vault одним запросом
3. Если есть встречи → Meeting Prep workflow (10 мин)

### Еженедельная рутина (пятница, 30 мин)

1. Perplexity Deep Research по одной активной теме (AMC / EDA / ZILLI ротация)
2. Claude: синтез → обновить Project-файл в vault
3. Claude: проверить project_active_digest, обновить если что изменилось
4. ChatGPT: аудит промптов (раз в месяц, не каждую неделю)

## Часть VIII. Быстрая справка

### 10 правил эффективного промпта

1. Роль + задача + формат + ограничения — минимальная структура
2. Всегда указывай язык
3. Указывай объём («до 200 слов», «1 страница A4»)
4. Негативные инструкции — «без bullet points», «без вступления»
5. Батчинг — несколько вопросов = один запрос
6. Один разговор = одна тема
7. Не вставляй файл повторно если только что читал
8. XML-теги для сложных задач
9. Fail-fast для Perplexity — «Cite sources or mark UNVERIFIED»
10. Haiku для рутины в n8n
