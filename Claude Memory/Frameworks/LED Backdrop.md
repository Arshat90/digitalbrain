# LED Backdrop — Шаблон

Фреймворк для создания циклирующегося **LED-backdrop** в Bloomberg/РБК-стиле для корпоративных мероприятий холдинга Almaly (Акционер / Набсовет / Правление / ГД ДЗО). Deliverable — **самодостаточный HTML-файл** (~100–150 КБ).

## Технические инварианты

- **Цикл:** 8 сцен × 10 сек = 80 сек. На 15–20 мин фона = 11–15 повторов.
- **Мёртвая зона:** нижние 20% экрана — только бегущий тикер. Контент сцен заканчивается на ~80% высоты.
- **Типографика:** `clamp()` с привязкой к viewport-height — корректно на 768–1440 px без перелива.
- **Логотип:** зашивается через base64 data-URI (самодостаточность). Шрифты — Montserrat (Google Fonts; нужен интернет на event-машине).
- **Элементы Bloomberg-стиля:** ON AIR pulse (хедер), бегущая строка (тикер внизу), count-up анимация, grow-bars.
- **Палитра Almaly:** бордовый (`#8B1A2D`), золото (`#C9A84C`), sage-mint акцент (`#7BC68A`), тёмный фон.
- **Подача:** только позитив в public-слоях; NS-конфиденциальные данные (долг, проблемные ДЗО) — не выводить.

## Стандартная структура 8 сцен

| № | Название | Тип контента |
|---|----------|-------------|
| 1 | Headline-результат | Одна крупная цифра (выручка / основной KPI) |
| 2 | Dashboard 4 карточек | Выручка / EBITDA / Упр. ЧП / CAPEX |
| 3 | Beat-the-Plan (grow-bars) | Факт vs план по ключевым ДЗО |
| 4 | Траектория выручки | 3–4 точки прошлое → факт → цель |
| 5 | Центральная сцена | Стратегическое послание (цель + срок) |
| 6 | EBITDA milestones | 3 точки с маржой (%) |
| 7 | ТОП-6 ДЗО портфеля | Логотипы / названия + ключевая метрика |
| 8 | «Холдинг в цифрах» | 6 тайлов с gold accent-полоской |

Кода (опционально): closing-подпись / логотип на весь экран.

Технические требования (обязательно):
- Единый самодостаточный HTML-файл, логотип через base64
- 8 сцен × 10 сек, цикл 80 сек, JS auto-loop
- Мёртвая зона: нижние 20% — только тикер; контент сцен до ~80% высоты
- Типографика через `clamp()` (работает 768–1440 px)
- Палитра: бордо `#8B1A2D`, золото `#C9A84C`, акцент `#7BC68A`, фон `#0A0A0F`
- ON AIR pulse в хедере, count-up на headline, grow-bars на Beat-the-Plan
- Шрифт Montserrat (Google Fonts)
- Не выводить: долг, Долг/EBITDA, проблемные ДЗО, кассовые разрывы

Сохрани в рабочую папку, дай ссылку. После — покажи превью логики каждой сцены.

## Чеклист перед event-машиной

- [ ] Интернет в зале? (Montserrat грузится с Google Fonts)
- [ ] Если нет — встроить WOFF2 локально (спросить IT заранее)
- [ ] Проверить в браузере на event-разрешении (обычно 1920×1080 или 3840×1080 LED)
- [ ] Убедиться, что логотип отображается (base64 не зависит от сети)
- [ ] Запустить полный цикл (80 сек) — нет ли перелива текста
- [ ] Тикер читается с расстояния 5–10 м (шрифт ≥ 18px)
