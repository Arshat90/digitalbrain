## State (frontmatter)

- `sync_last_run_at` — UTC ISO timestamp последнего успешного прогона
- `sync_last_run_status` — `success` | `partial` | `failed`

- `sync_captured_recent` — последние ~100 captured session IDs (FIFO truncate; v3.6 с 2026-06-11, до этого ~50)
- `last_anomalies` — последние известные проблемы (bash unavailable, REST timeout, search_replace 0-match, scheduler serialization)
